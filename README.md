# API REST - Gerenciamento de Produtos

API RESTful para cadastro e controle de produtos desenvolvida com Node.js, Express, TypeScript, Sequelize e banco de dados relacional SQLite. O projeto conta com testes automatizados utilizando Jest e Supertest, atingindo mais de 90% de cobertura de código.

## Tecnologias Utilizadas

- **Linguagem:** TypeScript
- **Framework Web:** Express
- **ORM / Banco de Dados:** Sequelize com SQLite (`database.sqlite`)
- **Testes:** Jest & Supertest
